# Compatibility matrix — APIPatch 0.1

[English](COMPATIBILITY.en.md) · [Español](COMPATIBILITY.md)

“Supported” means the pattern is implemented and tested, not that every program containing it can be repaired. Reports include evidence, confidence, pending work, and limitations. Semantic equivalence must come from a migration file.

| Area | Supported | Manual review or out of scope |
| --- | --- | --- |
| Specifications | OpenAPI 3.0.x/3.1.x in JSON/YAML; paths, methods, parameters, bodies, responses, security requirements; local references within a permitted root and bounded recursive references, including dependentSchemas/contentSchema. A 3.1 document without paths loads. | Remote references, dynamicRef, anchor, complete JSON Schema dialects, files outside the root, and documents over size limits. 3.1 webhooks load with a diagnostic but are not compared. Invalid references are errors. |
| Comparison | Removed/added operations; required/removed parameters; types, enums, request/response requirements and properties; HTTP responses, media types, authentication requirements. Rules account for request versus response direction. Recursive schema references are compared structurally with cycle detection; object-like `allOf` branches are merged and compared with the normal rules; `anyOf` branch additions and removals are classified by direction. | Semantic renames, complete authentication schemes, style/explode, encoding, response headers, links, callbacks. `oneOf`, `not`, `if`/`then`/`else`, discriminator and non-mergeable `allOf` changes are ambiguous; `anyOf` branches are paired by position. A recursive reference that cannot be resolved is reported as ambiguous. Detected but uninterpreted variations are ambiguous, not silently compatible. |
| Consumer repositories | JS/TS extensions .js, .jsx, .ts, .tsx, .mjs, .cjs, .mts, .cts; TypeScript AST; fetch, direct node-fetch/cross-fetch imports, axios, axios.create, require('axios'); literal HTTP methods; literal URLs, simple dynamic path templates, immutable local constants, simple concatenation, resolvable new URL. | Custom wrappers, mutable values, cross-module flow, computed methods/URLs, unresolved axios bases, and complex transforms. Unknown API origin is at most a low-confidence hint. |
| Matching | File and range, method/path, candidate operation, AST/schema evidence, confidence and reason. Known origins are compared with OpenAPI servers. | Similar text alone never proves a call or authorizes a patch. Third-party URLs and unknown methods stay unconfirmed. |
| Repair | Explicit operation mapping with the same method/server, query rename, JSON request key rename and configured literal values at the top level or at an explicit nested `parent` path through plain object schemas, response property-access chains (including optional chaining) and `const`/`let` object destructuring of the response; preview, diff, explicit apply with file hashes. | Low-confidence/unresolved uses, ambiguous changes, method/server changes, nested fields through arrays/oneOf/anyOf/additionalProperties/recursive schemas, nested query parameters, spreads/computed properties, shared URL/objects, some concatenated URLs, destructuring with rest/computed keys or in parameters/assignments, aliases of response objects, element/dynamic response access, calls through repository wrappers (reported, never edited), targets absent from OpenAPI. Partial results retain explicit pending findings. |
| Verification | Levels 1 plan validity, 2 syntax, 3 applicable type checks, 4 opt-in packaged synthetic demo contract, 5 one repository command only with explicit authorization. | No general contract-test generator. Without demo-contract, level 4 is skipped; an unrelated plan is blocked. Skipped/blocked never count as passed. |
| Local panel | Workspace-bounded selection, review of findings/files/diff, verification display, JSON/Markdown/patch exports, explicit apply. Server binds 127.0.0.1 and uses a session token. | Browser selection remains inside the chosen workspace; the panel never runs repository tests or an arbitrary contract. Use the CLI with explicit authorization for level 5. |

See [comparison rules](../src/compare/RULES.md), [repair limits](../src/repair/REPAIRS.md), [architecture](ARCHITECTURE.md), and [validation](VALIDATION.md) for details.

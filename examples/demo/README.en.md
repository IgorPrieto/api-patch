# Synthetic demo artifacts

[English](README.en.md) · [Español](README.md)

These files were generated by the CLI from `demo/specs/v1.yaml`, `demo/specs/v2.yaml`, and `demo/repository` on 2026-10-01. They are **synthetic** and preserve observed local execution results, not customer metrics. Absolute paths were normalized to `./` for publication. The example plan is not portable to another checkout: rerun the commands to obtain current hashes and paths before any application.

- [analysis.json](analysis.json): 8 API changes, 4 HTTP uses, and 5 findings; two ambiguous findings remain pending.
- [report.en.md](report.en.md): English report headings with verbatim technical explanations. Exported JSON redacts captured URL expressions and values while retaining source file and range.
- [plan.json](plan.json) and [repair.patch](repair.patch): four proposed edits in `client.js`, not applied to the original.
- [verification.json](verification.json): levels 1/2 passed, 3 blocked by existing fixture type errors, 4 passed on 3/3 supported synthetic API cases, and 5 skipped without command authorization. The standalone CLI exited 5 because a level was blocked.

Reproduce from the package root after `npm ci && npm run build`:

```sh
node dist/cli/main.js demo --verify-level4
node dist/cli/main.js scan --old demo/specs/v1.yaml --new demo/specs/v2.yaml --repo demo/repository --out examples/demo/analysis.json
node dist/cli/main.js repair --report examples/demo/analysis.json --migration demo/migration.yaml --repo demo/repository --out examples/demo
node dist/cli/main.js verify --plan examples/demo/plan.json --repo demo/repository --demo-contract --out examples/demo/verification.json
```

The isolated `verify` command exits 5 for this example because type checking is blocked. A passed level 4 does not turn that into full verification or guarantee production behavior.
